## Overview

CTF_Flag_Hunter v5.0 is an educational automation framework for CTF and lab environments. It features multi-layer decryption, auto-solving, intelligent detection, and **SECURE DATA HANDLING** with encryption.

### Author

---

## Key Features

- **Multi-Layer Decryption**: Decodes Base64, Hex, ROT13, URL, Zlib, etc.
- **Intelligent Detection**: Auto-detects platform and flag formats
- **Multiple Methods**: HTTP, SSH, Local File
- **Secure Data Handling**: AES-256 encryption for results
- **Secure Storage**: Encrypted file storage with secure permissions
- **Platform Support**: HTB, THM, Bugcrowd, VulnHub, PicoCTF, OverTheWire
